## 2026-07-03 — arXiv→formal publication resolution + GB/T 7714 + enrichment cleanup
- **Changed**:
  - `utils/paper_search.py`: new `resolve_publication(rec, keep_preprints=False)` — queries DBLP
    (`dblp.uni-trier.de`, primary) then S2 (fallback) to find the formal published venue for an
    arXiv preprint. Returns updated rec (venue/year/doi) or None (preprint-only → dropped).
    Wired into `search_papers` as a post-filter. `make_bib_entry` no longer adds `arXiv:` notes
    for resolved papers (only genuine preprints). DOI line added when available.
  - `enrich_paper.py`: new `_cleanup_orphans(tex, bib)` — removes bib entries never `\cite`'d
    (fixes numbering gaps). Stronger `INSERT_PROMPT` (forces ≥10 `\cite`, allows related-work
    paragraph). `min_cite` param.
  - `templates/software_se/template.tex`: switched from `unsrt` to **GB/T 7714** national standard
    (`\usepackage[numbers,super]{gbt7714}` + `\bibliographystyle{gbt7714-numerical}`). Chinese
    papers now use [C]/[J] type markers, `et al.` after 3 authors, no arXiv trailing notes.
- **Why**: arXiv preprint citations are not acceptable in formal papers; citations should reference
  the published venue. Chinese papers need GB/T 7714 format. Enrichment had numbering gaps from
  orphan bib entries.
- **Wiki**: updated `concepts/paper-search.md` (resolution section), `concepts/enrich-paper.md`
  (cleanup + stronger prompt), `concepts/latex-templates.md` (GB/T 7714), `INDEX.md` timeline.
- **Verified**: SWE-bench arXiv:2310.06770 → ICLR (via DBLP); 6/6 search results for 'RTL bug
  localization' have formal venues; SE survey enriched to 22 refs, 19 formal venues, 0 orphans,
  0 errors, GB/T 7714 format renders correctly with [C]/[J] markers, no arXiv notes.
