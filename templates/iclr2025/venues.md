# Target Venues for Literature Search

When searching for related work and citations, prioritize papers published in the following top-tier Machine Learning venues:

## Primary ML Conferences
- ICLR (International Conference on Learning Representations)
- NeurIPS (Advances in Neural Information Processing Systems)
- ICML (International Conference on Machine Learning)
- AAAI (AAAI Conference on Artificial Intelligence)
- IJCAI (International Joint Conference on Artificial Intelligence)

## Journals
- JMLR (Journal of Machine Learning Research)
- IEEE TPAMI (Transactions on Pattern Analysis and Machine Intelligence)

## Preprints
- arXiv (cs.LG machine learning, cs.CL computation and language, stat.ML)
