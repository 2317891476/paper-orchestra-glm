# Target Venues for Literature Search

When searching for related work and citations, prioritize papers published in the following top-tier Computer Architecture and Systems venues:

## Primary Architecture Conferences
- ISCA (International Symposium on Computer Architecture)
- MICRO (IEEE/ACM International Symposium on Microarchitecture)
- HPCA (IEEE International Symposium on High-Performance Computer Architecture)
- ASPLOS (Architectural Support for Programming Languages and Operating Systems)

## Design Automation & Verification
- DAC (Design Automation Conference)
- DATE (Design, Automation & Test in Europe)
- ICCAD (International Conference on Computer-Aided Design)
- IEEE TVLSI (Transactions on Very Large Scale Integration Systems)
- IEEE TCAD (Transactions on Computer-Aided Design of Integrated Circuits and Systems)

## Systems & Performance
- USENIX ATC (USENIX Annual Technical Conference)
- OSDI / SOSP (Operating Systems Design & Implementation / Symposium)
- ACM TACO (Transactions on Architecture and Code Optimization)
- SC (International Conference for High Performance Computing)

## Preprints
- arXiv (cs.AR computer architecture, cs.ET emerging technologies, cs.LG when relevant)
