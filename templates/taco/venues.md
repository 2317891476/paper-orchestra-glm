# Target Venues for Literature Search

Prioritize papers from these top-tier Computer Architecture, Systems, and Code Optimization venues
(TACO's community):

## Primary Architecture Conferences
- ISCA, MICRO, HPCA, ASPLOS

## Code Optimization & Compilation
- PLDI, CGO, PPoPP, CC, PACT
- ACM TACO (Transactions on Architecture and Code Optimization)

## Systems & Performance
- OSDI, SOSP, USENIX ATC, EuroSys, SC
- ACM TOCS, IEEE TC, ACM TACO

## Design Automation & EDA (when relevant)
- DAC, DATE, ICCAD, IEEE TCAD

## Journals
- ACM TACO, IEEE TC, ACM TOCS, IEEE TPDS, ACM TOPC

## Preprints
- arXiv (cs.AR, cs.PF performance, cs.DC distributed, cs.PL programming languages)
